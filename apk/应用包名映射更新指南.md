# 应用包名映射更新指南

## 问题描述

当执行 "open app" 动作时，如果应用名称没有在映射表中，就无法打开应用。需要定期更新应用包名映射表。

## 解决方案

### 1. 获取手机上所有应用的包名

使用提供的脚本自动获取手机上所有已安装应用的包名和中文名称：

```bash
# 确保手机已通过ADB连接
adb devices

# 运行脚本获取应用列表
python get_app_names_with_labels.py [设备ID]

# 例如：
python get_app_names_with_labels.py 10CF67018U00315
```

### 2. 脚本输出

脚本会生成两个文件：

1. **app_package_mapping_final.json** - JSON格式的应用映射
2. **app_mapping_kotlin_final.txt** - Kotlin代码片段

### 3. 更新Android应用代码

将生成的Kotlin代码复制到以下文件中：

**文件路径：** `D:\agent\apk\app\src\main\java\com\agent\mobileagent\service\AutoAgentAccessibilityService.kt`

**函数位置：** `resolveAppPackage()` 函数（约第469-481行）

**更新步骤：**

1. 打开 `AutoAgentAccessibilityService.kt` 文件
2. 找到 `resolveAppPackage()` 函数
3. 将函数内容替换为生成的Kotlin代码
4. 保存文件
5. 重新编译APK

### 4. 编译和安装APK

```bash
cd D:\agent\apk

# 编译APK
gradlew assembleDebug

# 安装到手机
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 手动添加新应用

如果需要手动添加新应用到映射表：

1. 获取应用包名：
```bash
# 列出所有应用
adb shell pm list packages -3

# 查找特定应用
adb shell pm list packages | grep "关键词"
```

2. 在 `resolveAppPackage()` 函数的 `appPackageMap` 中添加：
```kotlin
"应用名称" to "包名",
```

## 注意事项

1. **应用名称大小写敏感** - 确保使用正确的大小写
2. **中文应用名** - 优先使用中文名称，因为模型更可能输出中文
3. **包名唯一性** - 每个包名在系统中是唯一的
4. **定期更新** - 当安装新应用后，需要重新运行脚本更新映射表

## 故障排查

### 问题：无法打开某个应用

**检查步骤：**

1. 确认应用已安装：
```bash
adb shell pm list packages | grep "应用关键词"
```

2. 检查映射表中是否包含该应用名称

3. 查看日志确认模型输出的应用名称：
```bash
adb logcat | grep "open_app"
```

4. 如果应用名称不在映射表中，按照上述步骤添加

### 问题：脚本无法连接设备

**解决方法：**

1. 确认ADB连接：
```bash
adb devices
```

2. 如果是网络ADB，先连接：
```bash
adb connect IP:端口
```

3. 如果是USB连接，确保USB调试已开启
